# 环境管理（Node / npm）

本应用运行 dsh 需要一个 **Node** 和一个 **npm**。本页说明两者的来源、版本化安装与切换，以及下载行为。相关界面在「设置 → 环境」。

## Node 运行时：三种来源

点标签即切换，**改动后需重启 dsh 生效**（页面下方有「立即应用」）。

| 来源 | 说明 |
|---|---|
| **程序内置** | 使用 Electron 自带的 Node；随应用一起升级，不能单独更新。最省事。 |
| **系统自带** | 使用你自己安装的 Node；显示当前版本与最新 LTS，落后时给出「前往下载」。应用**不会**改动系统安装目录。 |
| **本地部署** | 由应用下载并管理，装进 `<配置目录>/node/<版本>/`，**多版本并存**。 |

运行 DeepSeek Harness 要求 **Node ≥ 20**；选中更低的主版本会给出提示。

### 本地部署：安装与切换

- 打开版本下拉框，可选择任意版本（勾选「包含非 LTS（Current）」以显示非 LTS）；
- 点下载后显示进度与速度，**下载与解压都可取消**；解压阶段是独立动画；
- 下方「已安装版本」列出所有版本，可**切换**生效版本（只改指针、不重装）或**删除**；
- 如果 dsh 正运行在要覆盖的版本上，会先提示停止。

::: info
「最新 LTS」取自 nodejs.org 的发行索引，主进程缓存 10 分钟；离线或代理不通时显示「无法获取最新版本」。
:::

## npm 来源：三种来源

同样点标签即切换。

| 来源 | 说明 |
|---|---|
| **程序内置** | 首次使用时下载并解压到 `<配置目录>/npm/<版本>/`，由应用代管；多版本并存，可切换 / 删除。 |
| **系统自带** | 使用系统 npm；更新会执行一次**全局安装**，会真实改动系统全局 npm。 |
| **本机 Node 自带** | 使用「本地部署」那个 Node 自带的 npm；更新装进配置目录里的那个 Node。 |

每个标签显示**当前版本**与 **registry 最新版**；落后或未就绪时出现「下载 npm / 更新 npm」。下方共用一个**版本选择器**（可勾选「包含预发布」），能安装任意历史版本，作用于上方选中的来源。

### 版本列表为空时的回退

默认隐藏预发布 / 测试版；如果远端**只有**预发布版，列表会自动回退显示这些版本，避免出现空列表。

## 下载器

- Node / npm / 应用更新的文件下载为**多线程分段**（HTTP Range 并发）；并发数固定为**自动**（按本机 CPU 核心数取 2–8），不提供手动档；
- 进度条显示**已下载 / 总大小**与**实时速度**；
- 未完成的临时文件统一放在**工作目录下的 `temp/download`**，完成后再搬到目标位置；
- **同一目标文件**的重复请求会合并为同一个在途任务，后到的调用共享结果与进度，不会重复下载。

## npm 缓存

所有 npm 调用（DeepSeek Harness 安装、npm 自更新、内置 / 本地 Node 的 npm）的缓存目录统一指向**工作目录下的 `temp/npm`**，不写入用户主目录的 `~/.npm`。

# 应用更新与回退

本应用支持**后台自动更新**，并保留一份上一个版本用于**一键回退**。相关界面在「设置 → 关于」。

## 自动更新怎么工作

1. **检查**：开启后，启动时静默检查新版本（是否包含预发布由「检测测试版」控制）；
2. **后台下载**：有新版本时在后台下载，不打断你使用，进度可在关于页看到；
3. **静默提示**：下载完成后不再弹通知，只在状态栏版本项右上角显示小红点；点击版本项，可在浮层里选择「重启安装」，也可以稍后退出时自动安装；
4. **保留旧版**：安装前把当前版本**压缩归档**（只保留最近一版），作为回退来源；
5. **健康守卫**：新版启动后若连续失败，会自动回退到上一版。

## 手动更新与回退

- 在「设置 → 关于」可手动触发检查 / 更新；
- 也可点击状态栏右侧的「程序版本 · dsh 版本」项，在浮层里检查更新；
- 「回退到上一版」可立即回到归档的旧版本，适合新版出现问题时应急。

## 与 DeepSeek Harness 更新的区别

| | 更新对象 | 通道 | 在哪管理 |
|---|---|---|---|
| **应用自更新** | 本桌面外壳 | GitHub Releases | 设置 → 关于 |
| **DeepSeek Harness 更新** | `@deepseek-ai/dsh` | npm registry | 设置 → DeepSeek Harness |

两者互不影响：GitHub 不可达时应用自更新可能失败，但 DeepSeek Harness 更新仍可用，反之亦然。

## 如果更新卡住

- 检查网络；需要走代理时，在「设置 → 常规 → 网络」启用代理并勾上**程序更新**（应用自更新）与**版本查询**（DeepSeek Harness）；
- 应用更新与 DeepSeek Harness 更新走不同通道，可分别排查；
- 更详细的排查见[常见问题](/zh/user/faq)。

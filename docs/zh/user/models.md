# 模型与余额

「设置 → 模型」列出 dsh 各供应商提供的模型及其余额。数据由主进程读取与联网查询，**页面不展示任何密钥**。

## 首次进入：先征求同意

首次进入该页会显示一张同意卡片，说明将读取 dsh 配置目录（`$DSH_HOME`，未设置时为 `~/.dsh`）下的 `cordis.patch.yml`（供应商配置）与 `.credentials.yaml`（API 密钥），并用其中保存的密钥向供应商接口查询模型目录与余额。

- 点「同意并读取」后才开始读取与联网；同意状态保存在本机（配置目录 `settings.json` 的 `modelsCredConsent`），以后进入不再询问；
- 点「暂不」会在本次访问收起卡片，页面显示「尚未授权读取」，之后可随时重新授权；
- 未同意前**不读配置、不联网**。

## 三列含义

| 列 | 说明 |
|---|---|
| **模型** | 供应商提供的模型标识；供应商未公布目录时以配置里声明的为准。 |
| **供应商** | 模型所属的服务商。**同一令牌只算一个服务商**：多个路由解析到同一个密钥时会合并成一组，只展示一次。 |
| **余额** | 当前余额。只有 DeepSeek 官方域可查（走 `/user/balance`）；其它供应商显示「不支持查询」，未配置密钥的显示「未配置密钥」，查询失败则显示失败原因。 |

余额项悬停可看到赠送 / 充值明细。

## 刷新全部

工具栏的「刷新全部」会重新读取配置并联网查询所有供应商的模型目录与余额；左侧同时显示当前模型数量。若配置文件缺失或无法解析、尚未配置供应商，页面会给出对应的提示。

## 隐私

- `.credentials.yaml` 里的密钥只由**主进程**读取，仅用于向对应供应商接口发起请求；
- 密钥绝不进入 IPC 返回值、页面内容或日志；
- 请求只从本机发起，结果只用于展示，不写入日志、也不发送到别处。

## 与状态栏余额的关系

状态栏右侧的余额项显示的是**当前默认模型所属供应商**的余额：已授权时前台每 5 分钟自动刷新，点击可手动刷新；未授权时显示「点击授权」，点击即跳转到本页。

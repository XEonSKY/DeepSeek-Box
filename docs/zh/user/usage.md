# 界面与操作

应用是无边框桌面外壳：上部是自绘标题栏（含浏览器式标签条），下部是网页内容区。本页介绍日常操作。

## 标题栏（从左到右）

| 区域 | 说明 |
|---|---|
| 应用图标 + 名称 | 显示 DeepSeek Box |
| 固定站图标 | 仅**核心窗口**显示：DeepSeek UI / 网页对话 / 用量充值 |
| 跳转核心窗口 | 仅**副窗口**显示，用于回到承载 DeepSeek UI 的那个窗口 |
| 标签条 | 动态标签 + `＋` 新建（三个固定站不在这里）；空白处可拖动窗口、滚轮横向滚动 |
| 刷新 | 仅当前激活的是三个固定站之一时显示 |
| 设置 | 打开设置页（终端也在设置里：设置 → 终端） |
| 最小化 / 最大化 / 关闭 | 窗口控制 |

::: tip
设置是**覆盖层**：底下的网页不会卸载，切回来仍是原状态。
:::

## 标签页

### 固定站图标（仅核心窗口）

三个固定站是**标题栏左侧的图标按钮**，始终存在、**不可关闭**，也不在标签条里：

1. **DeepSeek UI** —— 内嵌的 dsh 主界面；
2. **网页对话** —— 内嵌 [chat.deepseek.com](https://chat.deepseek.com/)；
3. **用量 / 充值** —— 内嵌 [platform.deepseek.com](https://platform.deepseek.com/)。

### 动态标签

- 来源：页面内链接的 `target=_blank` / `window.open`，或点标签条上的「＋」；
- 数量不设上限；
- **保活策略**：同时保活的网页为「固定站 + 你加星的标签 + 最近 3 个未加星的动态标签」。超出范围的动态标签**仍留在标签条上**，只是网页被回收，切回时重新加载；
- 标签只有**被打开过**之后才会真正加载网页。

### 「＋」新建标签

点「＋」打开的是**程序内置的标签页导航**（不是网页）：上方一个「跳转」输入框 + 三个固定站入口，扩展 `xeonsky.browser` 启用时还会显示你在扩展设置里添加的**常用站点**。

- **跳转框**是**跳转**语义 —— 输入网址就打开它，不是网址就补 `https://` 当作域名打开，**不会**替你搜索（要搜索用地址栏）；

### 标签操作

| 操作 | 效果 |
|---|---|
| 单击 | 切换到该标签 |
| `Ctrl` / `Cmd` + 单击 | 用**系统默认浏览器**打开该标签网址 |
| 中键单击 | 关闭标签 |
| 星标（☆） | 保活固定：网页常驻，且**不占用**最近 3 个保活名额 |
| 拖动标签 | 在标签条内**重新排序**；拖到另一个窗口的浅蓝遮罩可**移入该窗口** |
| 右键 | 复制 / 关闭 / 在新窗口打开 / 移动到其它窗口 |

## 地址栏

地址栏**仅在动态标签激活时显示**（固定站不显示）。

| 输入 | 行为 |
|---|---|
| `http(s):` / `about:` | 在应用内加载 |
| 其它协议（`mailto:`、`tel:`、自定义协议等） | 交给系统默认程序打开 |
| 不是网址的内容 | 用设置的**默认搜索引擎**搜索 |

地址栏左侧还有**后退 / 前进 / 刷新**（加载中变为停止）。

## 多窗口

- 在标签上右键「**在新窗口打开**」，即可开出一个**完整副窗口**（自带标签条）；
- 副窗口**没有**三个固定站，标题栏位置显示「**跳转核心窗口**」；
- 副窗口标题为「当前标签页标题 - 软件名」；
- **核心窗口关闭后**，最早打开的副窗口自动**接管**成为新的核心窗口。

## 右键菜单

在输入框或选中的文本上右键，会给出**剪切 / 复制 / 粘贴 / 全选**：

- 输入框里三项齐全；只选中文本（不可编辑）时给出「复制 / 全选」；
- 既没选中、也不在输入框里时**不弹菜单**（标签条有另一套右键菜单）；
- 内嵌网页里的输入框同样支持。

## 键盘快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl` / `Cmd` + `Alt` + `H` | **系统全局**：任何程序里按下都回到主窗口 |
| `Ctrl` / `Cmd` + `T` | 在网页视图与「设置 · 终端」之间切换 |
| `F12` | 打开 / 关闭 DevTools（**仅当「开发模式」开启时生效**；该开关默认隐藏，需在「设置 → 关于」连点应用版本号 5 次解锁） |

三者都可在[设置 → 快捷键](/zh/user/settings)里修改，「清空」即禁用。

## 托盘

关闭到托盘后：

- 单击：显示 / 隐藏窗口；
- 右键菜单：「显示 / 隐藏窗口」「退出（同时结束 dsh）」。

::: info
关闭窗口并不结束 dsh；真正退出时应用会同步结束它管理的 dsh 进程，避免残留。若没有可用托盘，关闭最后一个窗口会直接退出应用。
:::

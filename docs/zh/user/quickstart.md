# 快速开始

安装完成后，第一次启动应用即可使用。

![DeepSeek Box 主界面](/home-page.png)

## 第 1 步：启动应用

双击桌面图标或开始菜单快捷方式。应用会先检查 DeepSeek Harness 是否就绪：

- 已就绪：直接启动 dsh 并嵌入主界面；
- 未检测到 DeepSeek Harness：显示全屏**安装向导**（见第 2 步）。

## 第 2 步：跟着向导完成初始化

向导一共四步，每一步点「执行并下一步」：

| 步骤 | 你会看到 | 拿不准怎么选？ |
|---|---|---|
| 1. 镜像源 / 配置目录 | 官方源 / npmmirror 镜像；配置目录可「选择…」或「恢复默认」 | 国内选 **npmmirror**，更快；配置目录保持默认即可 |
| 2. Node 环境 | Electron 自带 / 系统自带 / 本地部署 | 本机没装 Node：选 **本地部署**；不想额外下载：选 **Electron 自带** |
| 3. npm 环境 | 程序内置 / 系统自带 / 本机 Node 自带 | 选 **程序内置** 最省心 |
| 4. 安装 DeepSeek Harness | 版本下拉框 + 安装按钮 | 直接用默认版本，点「安装 DeepSeek Harness」 |

几点说明：

- 选择「本地部署 Node」或「程序内置 npm」时，应用会**先自动下载对应运行时**（显示进度），完成后才进入下一步；
- 每一步都可以选**具体版本**：Node 可勾选「包含非 LTS（Current）」，npm 可勾选「包含预发布」；若远端只有预发布版，列表会自动显示它们而不是空白；
- 下载与解压过程都可以**取消**，解压阶段有独立动画；
- 同一时刻只会显示一个加载动画。

安装完成后应用会自动启动 dsh，出现 Web UI 即代表就绪。

## 第 3 步：认识主界面

启动后的界面由三部分组成：

1. **顶部标题栏**：左侧是应用名与**三个固定站图标按钮**（DeepSeek UI / 网页对话 / 用量充值）；旁边是浏览器式标签条，承载动态标签与右侧的 `＋` 新建；最右侧是刷新、设置、最小化 / 最大化 / 关闭。
2. **主区域**：左侧竖栏是 DeepSeek Harness 标识、「新会话」与「工作区」列表；中间是欢迎语、工作区 / 模式选择、输入框与模型选择。
3. **左下角「设置」**：打开设置页（覆盖层，不打断当前网页）。

完整说明见[界面与操作](/zh/user/usage)。

## 第 4 步：开始使用

- 在「工作区」里选择或打开一个文件夹；
- 点「新会话」，在输入框里描述你想做的事；
- 一切都在本机运行，默认只监听 `127.0.0.1`。

# 设置说明

「设置」通过左侧分组调整：常规、外观、网络、环境、DeepSeek Harness、模型、终端、快捷键、Webview、关于。所有设置卡都可点标题**折叠**。本页逐项说明。

## 常规

| 设置项 | 作用 |
|---|---|
| **工作目录** | dsh 启动所在目录；留空使用配置目录下的 `workspace`。 |
| **配置文件夹** | 应用设置、本地 DeepSeek Harness、内置 npm、本地 Node 与默认工作区的位置。默认 `~/.dsbox/release`（正式版）/ `~/.dsbox/dev`（开发版）。可「更改」或「恢复默认」。 |
| **端口** | 自动（从 3080 起挑空闲端口，推荐）或手动指定。 |
| **关闭按钮行为** | 隐藏到托盘或直接退出；可选「每次询问」或「记住选择」。 |
| **恢复默认设置** | 一键重置并重启 dsh。 |

### 配置文件夹的更改与迁移

更改**不会立刻搬迁**，而是提示「重启后自动迁移」：

- 选择「取消更改」即撤销本次修改；
- 重启后显示**迁移进度框**（进度条 + 当前正在移动的文件），成功后才把当前目录指向新位置；
- 旧版默认目录 `~/.config/dsh_shell[_dev]`（以及中间版本用过的 `~/dsbox/{release,dev}`）会在下次重启时自动迁移到新位置。

### 新标签页与搜索

| 设置项 | 作用 |
|---|---|
| **默认搜索引擎** | 地址栏输入非网址内容、内置导航页搜索时使用（百度 / 搜狗 / 360 / Bing / Google / DuckDuckGo）。 |
| **新标签页** | 点「＋」时打开**内置导航页**（搜索框 + 常用站点）或**自定义网址**。 |
| **常用站点快捷方式** | 名称 + 网址列表，显示在内置导航页上。 |

## 外观

| 设置项 | 作用 |
|---|---|
| **主题** | 跟随系统 / 浅色 / 深色，切换即时生效。 |
| **配色方案** | 7 套预制方案（默认蓝 / 极客紫 / 森林绿 / 青碧 / 暖橙 / 玫瑰红 / 石墨灰），同时决定主色与页面 / 侧栏底色，深浅两套自动适配。 |
| **语言（二级下拉）** | 选择 中文 / English，并选择扩展翻译（zh：简体 / 二次元 / 文言 / 繁体中文；en：English / 海盗腔 / 莎翁腔）。扩展翻译是**文本覆盖**，只影响当前语言，不改 dsh 设置。 |
| **界面缩放** | 50%–200%，作用于外壳窗口与内嵌 webview。 |
| **禁用系统缩放** | 忽略操作系统显示缩放，需重启生效。 |

## 网络

| 设置项 | 作用 |
|---|---|
| **npm 镜像源** | 官方 `registry.npmjs.org` 或 `npmmirror`。 |
| **代理** | 启用 + 协议（HTTP / SOCKS5）+ 主机 + 端口 + 代理范围。六个范围各自独立、互不牵连：**程序本体**（模型 / 余额查询与内嵌网页）、**程序更新**（应用自更新）、**DSH 本体**（dsh 进程自己的联网）、**npm 安装 / 下载**、**Node 下载部署**、**版本查询**（npm registry 上的版本列表与更新检查）。未勾选的范围跟随系统设置。 |
| **下载并发数** | 多线程分段下载的并发连接数。默认 **自动**（按本机 CPU 核心数取 2–8），也可手动指定 1–16：1 = 单线程。 |

下载的进度、临时目录、去重等行为详见[环境管理](/zh/user/environment)。

模型列表、供应商与余额，详见[模型与余额](/zh/user/models)。首次进入需先同意读取本地配置；页面**不显示任何密钥**。

## 终端

- dsh 的实时输出（stdout / stderr），带 ANSI 颜色；可切换**自动滚动**、**清空显示**；
- 终端是**只读**的（不接受键盘输入）；dsh 尚未输出时显示占位提示；
- 切走再回来会重新拉取最近输出（服务端环形缓冲，上限 5000 行）；
- 按 `Ctrl` / `Cmd` + `T` 在网页视图与「设置 · 终端」之间切换。

## 快捷键

| 快捷键 | 默认 | 范围 |
|---|---|---|
| 返回主窗口 | `Ctrl` / `Cmd` + `Alt` + `H` | **系统全局**，任何程序里都能把主窗口调到前台 |
| 切换终端视图 | `Ctrl` / `Cmd` + `T` | 应用内：网页视图 ↔ 设置 · 终端 |
| DevTools 控制台 | `F12` | 应用内：仅「关于 → 开发模式」开启时生效 |

- 点「修改」后按下组合键（`Esc` 取消）；「清空」= 禁用，「恢复默认」= 回到默认值；
- 只支持字母 / 数字 / F1–F24，且必须带至少一个修饰键；
- 系统全局快捷键可能被别的程序占用，占用时页面会提示，换一个即可；
- 改动即时生效，不需要重启。

## Webview

内嵌页面（dsh Web UI、网页对话、动态标签）的渲染方式与浏览器标识。

- **硬件加速**：默认开启。关闭可降低资源占用、兼容老旧驱动，但滚动与动画会变卡。它只能在**应用启动时**决定，改动需要重启应用。
- **UserAgent**：留空即用默认值，按当前平台与版本实时生成，形如 `... Chrome/<Chromium 版本> Safari/537.36 XEonSKY/<应用版本>`；自定义 UA 对**新请求**立即生效，已加载页面刷新后生效。

## 关于

- 显示应用版本与运行架构；
- **自动更新**：启动时检查应用新版本并后台下载，详见[应用更新与回退](/zh/user/update)；下载完成后状态栏版本项会显示小红点，点击可「重启安装」；
- **检测测试版**：是否包含预发布版本；
- **开发模式**：**默认隐藏**，在「设置 → 关于」**连点「应用版本号」5 次**（1.5 秒内连击）解锁后才会出现该开关；开启后 `F12` 可开关 DevTools（快捷键可在「快捷键」页改）。

::: tip 彩蛋
在「关于」页**连点「应用版本号」5 次**可解锁上面的「开发模式」开关；**连点「系统架构」徽标 5 次**则会打开一个井字棋小游戏。
:::

## 状态栏

窗口底部是只读状态栏，右侧依次显示：

| 项 | 说明 |
|---|---|
| **当前供应商余额** | 已授权时显示余额，前台每 5 分钟自动刷新，点击可手动刷新；未授权时显示「点击授权」，点击跳转到「设置 → 模型」；悬停可看赠送 / 充值明细。 |
| **程序版本 · dsh 版本** | 形如 `v0.1.5-rc-1 · dsh 0.1.5-rc.2`。点击弹出浮层检测更新；检测到新版本时**只在版本项上显示小红点**（静默提示，不弹通知），浮层里可查看程序与 dsh 两条版本线的状态。 |

::: info
主题与语言会同步写入 dsh 的 Cordis patch 层（`$DSH_HOME/profiles/web/cordis.patch.yml`）；应用自身设置存在**配置目录**的 `settings.json`。
:::

# DeepSeek Harness 管理

DeepSeek Harness 是真正驱动 dsh Web UI 的程序，npm 包名为 `@deepseek-ai/dsh`，命令为 `dsh`。本页说明如何安装、更新、切换与卸载。相关界面在「设置 → DeepSeek Harness」。

## 来源

| 来源 | 说明 |
|---|---|
| **内置**（默认） | 由应用安装到配置目录的 `dsh/<版本>/`，并用选定的 Node / npm 运行；可在应用内安装、更新、切换版本。 |
| **全局** | 使用你系统里 `npm install -g @deepseek-ai/dsh` 装好的 dsh；应用不代管其版本。 |

选「全局」时需要指定**启动器路径**（用文件选择器选取）。

## 启动设置

「设置 → DeepSeek Harness」页还有整块**启动**设置：

- **超时**（`timeoutMs`）：等待 dsh 启动并打印地址的毫秒数，默认 90000ms；
- **运行状态与按钮组**：显示当前处于「运行中」还是「已停止」，并提供**启动 / 停止 / 重启**；
- **立即应用**：保存当前设置并立即应用（会重启 dsh 使其生效）。

## 首次安装

未检测到 DeepSeek Harness 时，应用会弹出**安装向导**：选择镜像源、是否包含测试版、要安装的版本，点「安装 DeepSeek Harness」。安装完成后自动启动 dsh。

## 检查与更新

- 可在「设置 → DeepSeek Harness」勾选**启动时检查**与**包含测试版**；
- 点「检查 / 更新 DeepSeek Harness」对比当前与最新版本；
- **已是最新时不再弹提示**，结果会在按钮下方回显一行（含远端解析到的版本号）；检测到新版本时，状态栏版本项会亮起小红点。

## 切换 / 回退版本

- 刷新版本列表（受「检测测试版」与镜像源影响）；
- 选择任意历史版本即可安装 / 切换（升级或回退）。版本列表默认隐藏测试版；若远端只有测试版，会自动回退显示；
- 内置版本按 `dsh/<版本>/` 存放，**多版本并存**；「已安装版本」可在其中**切换**（只改生效指针，不重装）或删除。

## 卸载

点「卸载 DeepSeek Harness」会先停止 dsh 再移除，之后回到安装引导。若卸载失败，应用会检测目录占用原因（进程引用、只读、安全软件锁定）并提示。

::: warning 升级 / 切换 / 卸载时
这些操作会**先安全停止所有运行中的 dsh 实例**（正在运行会先弹确认）。成功后自动重启以运行新版本；失败会尽量恢复原运行态并给出原因。
:::

## 网络与镜像

版本列表、更新检查与安装 / 卸载都走 npm。默认官方源 `registry.npmjs.org`，国内可切换到 `npmmirror`。

## 与「应用自更新」的区别

- **DeepSeek Harness 更新**：更新 `@deepseek-ai/dsh`（走 npm），在本页管理；
- **应用自更新**：更新本外壳应用（走 GitHub 发布），在[关于页](/zh/user/update)管理。
